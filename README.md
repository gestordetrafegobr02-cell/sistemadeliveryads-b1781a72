# Sistema Delivery ADS

Plataforma completa de gestão para delivery. Cardápio digital, pedidos via WhatsApp, painel administrativo e muito mais.

## Tecnologias

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Supabase (banco de dados, autenticação, storage)

## Desenvolvimento

```sh
npm install
npm run dev
```
